# Adverbs of Frequency

Site estático A1-A2 com advérbios, expressões de frequência, pronúncias simplificadas, exemplos, traduções e um visualizador de combinações.

## Publicação

O site pode ser publicado diretamente pelo GitHub Pages a partir do branch `main` e da pasta raiz.

## Arquivos

- `index.html`: estrutura da página
- `style.css`: identidade visual e responsividade
- `script.js`: conteúdo, áudio, traduções e combinações

O áudio usa a voz em inglês americano disponível no navegador do aluno.
